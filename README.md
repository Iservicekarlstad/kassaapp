# KassaApp – iService

Butikens interna kassa- och kalkylverktyg: https://iservicekarlstad.github.io/kassaapp/

Källfilen redigeras i `KassaApp.html` (lokalt i Desktop/CLAUDE/KassaApp) och kopieras hit som `index.html`.
Data (kassaregister, priser) ligger i Firebase och kräver den delade nyckeln – inget av det finns i det här arkivet.
